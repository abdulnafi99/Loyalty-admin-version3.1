Install iOS

Pasang di iPhone / iPad

Ikut langkah mudah berikut untuk pasang app ini di home screen anda

  1. Buka app ini menggunakan Safari (bukan Chrome atau lain)
  2. Tekan butang Share di bawah skrin
  3. Scroll dan pilih "Add to Home Screen"
  4. Tekan "Add" di kanan atas — siap! 🎉
Install App

Cara Pasang App

Pasang sebagai app untuk akses pantas tanpa buka browser

  1. Buka menu browser (⋮ atau ···) di kanan atas
  2. Pilih "Install app" atau "Add to Home screen"
  3. Tekan "Install" untuk sahkan
